# Level 2 — Conditions (if / else)

A collection of basic C programs demonstrating conditional control structures (`if`, `if-else`, and `else if` ladders) and formatted standard I/O.

---

## Problem Index

| Question No. | File Name | Description |
| :---: | :--- | :--- |
| **11** | `problem11.c` | Write a program to read a number and check whether it is even or odd. |
| **12** | `problem12.c` | Write a program to read a number and check whether it is positive, negative or zero. |
| **13** | `problem13.c` | Write a program to read three numbers and find the largest among them. |
| **14** | `problem14.c` | Write a program to read three numbers and find the smallest among them. |
| **15** | `problem15.c` | Write a program to read a year and check whether it is a leap year or not. |
| **16** | `problem16.c` | Write a program to read a character and check whether it is a vowel or a consonant. |
| **17** | `problem17.c` | Write a program to read a character and check whether it is an alphabet, digit or special symbol. |
| **18** | `problem18.c` | Write a program to read the marks of a student and print the grade (A/B/C/D/Fail). |
| **19** | `problem19.c` | Write a program to read a number and check whether it is divisible by both 3 and 5. |
| **20** | `problem20.c` | Write a program to read the age of a person and check whether they are eligible to vote. |

# Compile (example: problem16.c)

# Run on Windows
